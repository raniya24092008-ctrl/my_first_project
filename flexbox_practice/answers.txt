# Практическая работа №4. Построение layout с помощью Flexbox
## Ответы на вопросы для самоконтроля

**1. Какое основное свойство CSS включает Flexbox и что происходит с дочерними элементами после его применения?**

Flexbox включается свойством `display: flex`, которое пишется у родителя. После этого:
- Родитель становится **flex-контейнером**
- Его прямые дочерние элементы становятся **flex-элементами**
- Они выстраиваются в одну линию вдоль главной оси (по умолчанию слева направо)
- Блочные элементы перестают занимать всю ширину, а по высоте элементы по умолчанию растягиваются до самого высокого в ряду

> *На вложенные элементы внутри детей это свойство не действует, для них нужно задавать `display: flex` отдельно.*

---

**2. В чем разница между `justify-content` и `align-items`? Приведите примеры использования каждого.**

- `justify-content` выравнивает элементы по **главной оси**
- `align-items` выравнивает их по **поперечной оси**

Если направление `row`, то `justify-content` работает по горизонтали, а `align-items` — по вертикали.

**Примеры из работы:**
- `justify-content`: `.footer-content { display: flex; justify-content: space-between; }` — распределяет разделы футера по всей ширине.
- `align-items`: `.header { display: flex; align-items: center; }` — ставит заголовок по центру шапки по вертикали.

---

**3. Что делает свойство `flex-direction` и какие значения может принимать? Как оно влияет на основную ось?**

`flex-direction` задаёт направление главной оси, то есть в какую сторону выстраиваются элементы.

**Значения:**
- `row` (по умолчанию) — слева направо
- `row-reverse` — справа налево
- `column` — сверху вниз
- `column-reverse` — снизу вверх

При `column` главная ось становится вертикальной, и тогда `justify-content` работает по вертикали, а `align-items` — по горизонтали.

> *В работе я использовал `flex-direction: column` в медиазапросе, чтобы на телефоне колонки шли друг под другом.*

---

**4. Объясните значение трёх свойств в сокращённой записи `flex: 1`. Что означают `flex-grow`, `flex-shrink` и `flex-basis`?**

Запись `flex: 1` примерно равна `flex: 1 1 0%`.

- **`flex-grow`** — задаёт, какую долю свободного места забирает элемент. Если у всех `1`, то место делится поровну.
- **`flex-shrink`** — задаёт, насколько элемент может сжиматься, когда места не хватает. Значение `1` значит, что может сжиматься наравне с другими.
- **`flex-basis`** — начальный размер элемента до распределения свободного места.

> *В итоге `flex: 1` делает элементы одинаковой ширины, как карточки в моей работе.*

---

**5. Как работает свойство `flex-wrap` и в каких случаях его следует использовать?**

По умолчанию стоит `nowrap`, и все элементы пытаются уместиться в одну строку, из-за чего они сильно сжимаются.

- `wrap` — разрешает перенос элементов на новую строку, когда они не помещаются
- `wrap-reverse` — переносит их в обратную сторону

Использовать нужно, когда элементов может быть много или экран может быть узким: карточки, галереи, теги, списки товаров.

> *В работе я поставил `flex-wrap: wrap` для блока `.content` с карточками.*

---

**6. Чем отличается `align-content` от `align-items` и когда применяется каждое из этих свойств?**

- `align-items` выравнивает элементы **внутри каждой строки** по поперечной оси.
- `align-content` распределяет **сами строки** внутри контейнера, поэтому работает только когда строк несколько (при `flex-wrap: wrap`) и есть свободное место по высоте. Если строка одна и `nowrap`, `align-content` ничего не меняет.

> *В работе у `.content` стоит `align-content: flex-start`, чтобы строки с карточками прижимались к верху, а не растягивались на всю высоту.*

---

**7. Как свойство `order` влияет на отображение элементов и в каких практических ситуациях оно может быть полезно?**

`order` меняет порядок показа flex-элементов без изменения HTML. По умолчанию у всех `0`, элементы идут по возрастанию значения `order`.

> *В работе я поставил `order: 2` первой карточке и `order: 1` второй, поэтому вторая карточка отображается первой.*

**Полезно, например:**
- На мобильных устройствах, когда нужно поднять важный блок выше
- Опустить боковую панель вниз

Но нужно помнить, что для скринридеров и переключения клавишей Tab порядок остаётся как в HTML, поэтому злоупотреблять `order` не стоит.

---

**8. Что такое "осевая линия" (main axis) и поперечная ось (cross axis) в Flexbox и как они связаны с `flex-direction`?**

- **Main axis** — главная ось, вдоль которой выстраиваются элементы
- **Cross axis** — поперечная ось, перпендикулярная главной

Их направление зависит от `flex-direction`:
- При `row` главная ось **горизонтальная**, а поперечная **вертикальная**
- При `column` главная ось **вертикальная**, а поперечная **горизонтальная**

Свойство `justify-content` работает по главной оси, а `align-items` — по поперечной, поэтому при смене `flex-direction` они как бы меняются местами.

---

**9. Как создать адаптивный макет с помощью Flexbox без использования медиа-запросов? Приведите пример.**

Нужно включить перенос строк через `flex-wrap: wrap` и задать элементам гибкую ширину через `flex-basis` с возможностью растяжения. Тогда на широком экране карточки стоят в одну строку, а на узком сами переносятся и занимают всю ширину.

**Пример:**
```css
.cards {
    display: flex;
    flex-wrap: wrap;
    gap: 1rem;
}
.card {
    flex: 1 1 250px;
}

Каждая карточка хочет быть не уже 250px. Если места на три в ряд не хватает, лишние переносятся на следующую строку и все растягиваются на свободное место.

---

**10. Какие преимущества дает использование `gap` вместо `margins` для создания промежутков между flex-элементами?**

- `gap` создаёт промежутки **только между элементами**, а не снаружи по краям, поэтому не нужно убирать `margin` у первого или последнего элемента
- Его достаточно написать один раз в контейнере, а не у каждого элемента
- Он одинаково работает между рядами и колонками при переносе (есть отдельно `row-gap` и `column-gap`)
- Не ломается, если поменять порядок через `order` или направление через `flex-direction`
