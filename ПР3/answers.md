# Практическая работа №3. Применение CSS: селекторы, каскад, наследование
## Ответы на вопросы для самоконтроля

### 1. В чем разница между селектором по классу и по ID с точки зрения специфичности и возможности повторного использования?
**Ответ:** У селектора по ID специфичность выше: `#id` это (1,0,0), а `.class` это (0,1,0). Поэтому правило с ID перебьёт правило с классом. Класс можно использовать на любом количестве элементов, и у одного элемента может быть несколько классов. ID должен быть уникальным на странице, поэтому использовать его повторно нельзя. Для стилей лучше брать классы, а ID оставлять для якорей и скриптов. В моей работе `#site-title` используется один раз для заголовка, а `.card` и `.important` можно применять сколько угодно раз.

### 2. Как работает каскад в CSS и в каком порядке применяются стили при конфликте правил?
**Ответ:** Каскад это набор правил, по которым браузер выбирает, какое из нескольких конфликтующих правил применить. Сначала смотрят на важность и источник (правила с `!important` сильнее обычных, стили автора сильнее стилей браузера), потом на специфичность селектора, а если и она одинаковая, то побеждает правило, которое записано в коде позже. В моей работе так работают абзацы: `p`, потом `.post p`, потом `.featured-post p` и самое сильное `.featured-post .intro`. Поэтому вводный абзац получился фиолетовым.

### 3. Рассчитайте специфичность для селекторов:
**Ответ:**
- `ul li.important`: один класс и два тега, это (0,1,2).
- `#site-title`: один ID, это (1,0,0).
- `.content > .featured-post`: два класса, это (0,2,0). Комбинатор `>` на специфичность не влияет.

### 4. Какие свойства в CSS наследуются по умолчанию, а какие нет? Приведите по 3 примера каждого типа.
**Ответ:** Наследуются в основном свойства, связанные с текстом: `color`, `font-family`, `line-height` (также `font-size`, `text-align`). Не наследуются свойства блока и оформления: `border`, `padding`, `background-color` (также `margin`, `width`). Чтобы не наследуемое свойство взяло значение родителя, нужно написать `inherit`. В работе я сделала так: `.card { padding: inherit; }`, и карточка взяла `padding` у `.examples`.

### 5. Как работает селектор `>` (дочерний селектор) и чем он отличается от селектора потомков (через пробел)?
**Ответ:** Селектор `>` выбирает только прямых детей, то есть элементы, которые лежат непосредственно внутри родителя. Селектор через пробел выбирает всех потомков на любой глубине вложенности. Пример из работы: `.content > article` выбирает статью, которая лежит прямо в `.content`, а `.post p` выбирает все абзацы внутри `.post`, даже если они вложены глубже.

### 6. Для чего используются псевдоклассы `:hover` и `:nth-child()`? В каких практических задачах они могут пригодиться?
**Ответ:** `:hover` срабатывает, когда на элемент наведён курсор. Его используют для кнопок, ссылок и пунктов меню, чтобы они подсвечивались. `:nth-child()` выбирает элементы по порядковому номеру среди соседей: `odd` и `even` для чередующихся строк (полосатые таблицы и списки), каждый третий элемент, первые несколько элементов. В работе я сделала `li:hover` для подсветки пунктов жёлтым и `li:nth-child(odd)` для серого фона нечётных пунктов.

### 7. Что делает правило `!important` и почему его следует использовать с осторожностью?
**Ответ:** `!important` делает свойство самым приоритетным и перебивает даже более специфичные селекторы. Осторожно использовать его нужно потому, что он ломает обычный каскад: потом такое свойство трудно переопределить (можно только другим `!important`), код сложнее читать и отлаживать. Его оправданно применять редко, например для служебных классов или чтобы перебить чужие стили. В моей работе `.important { color: #e8590c !important; }` перебил цвет из `li.important`, и пункты стали оранжевыми.

### 8. Как псевдоэлементы `::before` и `::after` расширяют возможности CSS и какой контент они могут содержать?
**Ответ:** `::before` и `::after` создают виртуальный элемент перед или после содержимого элемента, при этом HTML менять не нужно. Контент задаётся свойством `content`: это может быть текст, символ, кавычки, счётчик, картинка через `url()` или пустая строка для декоративной фигуры. В работе я добавила звезду после заголовка `h2` (`.post h2::after`), стрелку перед карточкой (`.card::before`) и кружок в футере. Важную информацию в псевдоэлементы класть не стоит, потому что их нельзя выделить, и поисковики их не читают.

### 9. В каком порядке браузер применяет CSS-правила при одинаковой специфичности селекторов?
**Ответ:** Если специфичность одинаковая, применяется то правило, которое находится в коде ниже. Если правила в разных файлах, побеждает то, что подключено позже (у меня `styles.css` подключён после `reset.css`). В моей работе у `li:hover` и `li:nth-child(odd)` специфичность одинаковая (0,1,1), поэтому `hover` я поставила после `nth-child`, чтобы подсветка при наведении работала и на нечётных пунктах.

### 10. Как инструменты разработчика в браузере помогают анализировать и отлаживать CSS-код?
**Ответ:** В DevTools на вкладке Elements можно выбрать любой элемент и в панели Styles увидеть все применённые к нему правила. Перебитые значения там зачёркнуты, поэтому понятно, какое правило победило. Во вкладке Computed показаны итоговые значения свойств. Можно прямо в браузере менять значения и отключать свойства галочкой, чтобы быстро проверить идею. Можно принудительно включить состояние `:hover`. Также можно посмотреть специфичность селектора при наведении на него. Режим устройств (Ctrl+Shift+M) помогает проверить медиа-запросы на разной ширине экрана.
