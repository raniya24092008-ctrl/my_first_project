# Практическая работа №5. Создание сетки на CSS Grid

## Ответы на вопросы для самоконтроля

## 1. Какое основное свойство включает CSS Grid и чем принципиально отличается от Flexbox?

**Ответ:** Grid включается свойством `display: grid` у родителя. После этого его прямые дети становятся элементами сетки, которые можно расставлять по строкам и колонкам.

Главное отличие в том, что Grid двумерный: он управляет и строками, и колонками одновременно. Flexbox одномерный, он выстраивает элементы либо в одну строку, либо в одну колонку. Ещё Grid сначала задаёт сетку, а потом в неё раскладывает элементы, а Flexbox больше подстраивается под содержимое. В моей работе вся страница сделана на Grid (`.grid-container`), а меню (`.navigation ul`) на Flexbox.

## 2. В чем разница между grid-template-columns и grid-auto-columns? Когда следует использовать каждое?

**Ответ:** `grid-template-columns` задаёт явные колонки, то есть сетку, которую мы описали заранее. `grid-auto-columns` задаёт размер колонок, которые браузер создаёт сам (неявные), когда элемент не помещается в явную сетку, например при `grid-column: 5` в сетке из трёх колонок или при `grid-auto-flow: column`. Так же работают `grid-template-rows` и `grid-auto-rows`.

Явные колонки нужны, когда структура известна заранее (макет страницы). Автоматические нужны, когда элементов может быть много и заранее не известно сколько. В работе так сделаны строки галереи:

```css
.gallery {
    grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
    grid-auto-rows: minmax(150px, auto);
}
```

## 3. Что делают функции repeat(), minmax() и auto-fit в определении grid-шаблона? Приведите примеры.

**Ответ:**

- `repeat(количество, размер)` повторяет размер колонки или строки несколько раз. Пример: `repeat(4, 1fr)` это четыре равные колонки (так сделан футер).
- `minmax(мин, макс)` задаёт размер в диапазоне. Пример: `minmax(250px, 1fr)` значит, что колонка не уже 250px, но может растягиваться.
- `auto-fit` (и `auto-fill`) сам считает, сколько колонок поместится в контейнер.

Вместе они дают адаптивную сетку без медиа-запросов:

```css
.gallery {
    grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
}
```

## 4. Как работают именованные grid-области и какие преимущества они дают при создании макетов?

**Ответ:** Сначала в контейнере через `grid-template-areas` рисуется схема страницы строками с названиями областей, а потом каждому элементу присваивается имя через `grid-area`.

```css
.grid-container {
    grid-template-areas:
        "header  header"
        "nav     nav"
        "main    sidebar"
        "footer  footer";
}
.header { grid-area: header; }
```

Преимущества: макет виден прямо в коде, как на рисунке, и его легко менять. Например, в медиа-запросе я просто поменяла схему на одну колонку, а HTML вообще не трогала.

## 5. Объясните систему нумерации grid-линий и как с помощью grid-column и grid-row размещать элементы.

**Ответ:** Линии сетки нумеруются с единицы, слева направо для колонок и сверху вниз для строк. Если колонок N, то линий N + 1. Отрицательные номера считаются с конца, `-1` это последняя линия.

Элемент размещается между линиями: `grid-column: 1 / 3` значит от первой линии до третьей (две колонки), `grid-row` работает так же. Можно писать `span 2`, то есть занять две колонки. Короткая запись это `grid-area: row-start / column-start / row-end / column-end`. Примеры из работы:

```css
.gallery-item:nth-child(1) { grid-area: 1 / 1 / 2 / 2; }
.gallery-item:nth-child(3) { grid-column: span 2; }
```

## 6. Что такое grid-gap (или gap) и чем он лучше margins для создания промежутков в сетке?

**Ответ:** `gap` (раньше `grid-gap`) задаёт промежутки между строками и колонками сетки, отдельно можно задать `row-gap` и `column-gap`.

Чем лучше margin:

- промежуток появляется только между элементами, а не по краям, поэтому не надо убирать отступ у последнего элемента;
- записывается один раз у контейнера, а не у каждого элемента;
- не влияет на размер самих элементов и не ломается, если элементы меняют порядок или переносятся.

В работе у галереи `gap: 1.2rem`.

## 7. Как свойства justify-items и align-items влияют на выравнивание grid-элементов?

**Ответ:** Эти свойства выравнивают элементы внутри своих ячеек. `justify-items` работает по горизонтали (вдоль строки), а `align-items` по вертикали (вдоль колонки). Значения: `start`, `end`, `center` и `stretch` (по умолчанию, элемент растягивается на всю ячейку). Для отдельного элемента есть `justify-self` и `align-self`.

В галерее я поставил `align-items: center`, поэтому плитки выравниваются по центру высоты строки, а `justify-items: stretch` растягивает их на всю ширину колонки.

## 8. В чем разница между auto-fill и auto-fit при создании адаптивных сеток?

**Ответ:** Оба создают столько колонок, сколько помещается в контейнер. Разница видна, когда элементов мало. `auto-fill` оставляет пустые колонки, они занимают место, и элементы остаются узкими. `auto-fit` схлопывает пустые колонки до нуля, и элементы растягиваются на всю ширину контейнера (если у них `1fr`).

Например, в контейнере 1000px при `minmax(250px, 1fr)` и двух элементах: с `auto-fill` два элемента займут по четверти ширины, а с `auto-fit` по половине. В своей работе я использовала `auto-fill` для обычной ширины и `auto-fit` в медиа-запросе.

## 9. Как создать сложные макеты с помощью grid-template-areas и какие правила именования областей существуют?

**Ответ:** Нужно написать схему строками: каждая строка это ряд сетки, а каждое слово в ней это ячейка. Если имя повторить, области объединяются. Точка `.` означает пустую ячейку.

Правила:

- у каждой строки должно быть одинаковое количество ячеек;
- область должна быть прямоугольной, буквой L или с дырой сделать нельзя;
- имя это обычный идентификатор без пробелов (например `main`, `sidebar`);
- каждая строка записывается в кавычках;
- после этого элементам указывается `grid-area` с тем же именем.

Для адаптивности достаточно переопределить схему в `@media`, как в моей работе:

```css
@media (max-width: 1024px) {
    .grid-container {
        grid-template-areas: "header" "nav" "main" "sidebar" "footer";
        grid-template-columns: 1fr;
    }
}
```

## 10. Какие преимущества дает CSS Grid перед другими методами верстки для создания сложных двумерных макетов?

**Ответ:**

- работает сразу с двумя измерениями, а не только с одной строкой или колонкой, как Flexbox;
- не нужны старые хаки с `float`, `inline-block` и позиционированием, а также лишние вложенные `div`;
- именованные области делают код читаемым;
- макет можно перестраивать в медиа-запросах, не меняя HTML;
- `repeat`, `minmax` и `auto-fit` дают адаптивность вообще без медиа-запросов;
- есть удобный `gap` и гибкое выравнивание в обе стороны;
- поддерживается всеми современными браузерами.
